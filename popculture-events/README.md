# PopCulture Events

Веб-ориентированная информационная система для управления мероприятиями в сфере популярной культуры.

Стек проекта:

- PostgreSQL
- Flask
- React
- Vite

Проект запускается локально на Windows без Docker.

## 1. Требования

На компьютере должны быть установлены:

- PostgreSQL 18.3
- Python 3.14.4
- Node.js 24.15.0
- npm 11.12.1

Проверка версий:

```bash
psql --version
python --version
node -v
npm -v
